# Local assets

- `site.css` and `site.js` are the shared, dependency-free styles and optional interactions.
- `favicon.svg` is the project's own paper-slip mark.
- `og-image.svg` and its 1200×630 PNG export are the social preview.
- `demo-poster.svg` is an explicitly labelled illustration, not a video still.
- The demo video is on YouTube (https://www.youtube.com/watch?v=2oqAtUKSwRc). The homepage links to it from the poster; no video file is stored here and no third-party player is embedded.

All assets are local. Product names are text examples in a synthetic catalogue; no affiliation.
